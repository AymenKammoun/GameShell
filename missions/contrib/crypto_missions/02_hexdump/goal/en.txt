Mission goal
============

You have received a locked payload in your Mail_Box. The package contains a password verifier executable.
Luckily for you, the password is hard-coded in clear text in the password verifier executable.
Try to find it using simple file inspecting.

**Useful Tip: The password starts with "pass"

Useful commands
==============

xxd file
    Hexdump a file

grep
    Search of a particular string pattern
